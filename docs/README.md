# 政策資料單頁閱讀室（可攜式靜態版）

此備份只包含已公開審查的安全站點程式與資料，不是原始9份附件的完整備份；原始4份CSV與5份交接文件、29筆隔離資料均不附上。

本包將四份 Grok 歷史 CSV 的 **94 筆安全公開線索**整併為單一頁面，預設開啟 CSV 集合。可跨檔搜尋、依原始 CSV／國家／主題／來源篩選並按日期排序；每筆保留原檔名及 CSV 列號。另保留 **16 筆官方選讀**、蒐集方法和 **91 個不同來源入口網址**。

29 筆未通過公開範圍的原始列不在本包。不要把原始附件、私人研究、未核實個人指控或敏感資料直接複製進網站。

## 執行與託管

純 HTML、CSS、JavaScript、JSON；沒有後端、登入、模型 API、API key、OpenAI SDK 或專屬 runtime。一般靜態 HTTP 主機即可提供本資料夾。不要用 file:// 直接開啟，因瀏覽器可能阻擋 JSON 讀取。

本機預覽（需已安裝 Python 3）：

    cd docs
    python -m http.server 8000

接著開啟 http://localhost:8000 。正式主機請將此資料夾的 index.html 與其他資產保持同層；所有資產使用相對路徑，適用根網域或專案子路徑。GitHub Pages 可使用靜態檔；本包附 .nojekyll，不需要建置。

本包沒有設定任何帳號、公開儲存庫、託管計費或部署工作流。實際可用性與免費額度由最終託管者政策決定，不能保證永久免費或永久在線。

## 檔案

- index.html：單頁閱讀介面、官方選讀與方法／來源目錄
- styles.css / app.js：響應式樣式、集合切換、篩選與排序
- grok.json：94筆安全公開歷史线索，保留日期精度、原檔名、列號及抽樣核對欄位
- data.json：16筆官方選讀與日期／附件／查核限制
- strategy.json：交接文件的方法摘要與76個候選來源
- expansion-sources.json：11個補充官方入口；不代表RSS/API已串接
- manifest.json：檔案雜湊、資料數與本包邊界

## 更新原則

1. 保留原始來源日期、事件／生效日、資料期、查核日及匯入日的區別，不從檔名或URL猜日期
2. 缺日期維持 null；月份只保留YYYY-MM，不虛構1日
3. 候選蒐集結果先留在私人待審區，人工查證與公開審查後才能加入網站
4. data.json 的項目與 index.html 內官方靜態卡片需一併更新；grok.json由app.js載入
5. 抽樣摘要與原稿安全節錄分欄保留，不把原稿自稱已查證當作驗證
6. 同網址可能更正；歷史資料與共用網址不算獨立佐證
7. 新增後先檢查JSON/JavaScript、篩選、空結果、日期排序、原文連結與敏感資料，再手動發布

本次仍是人工維護閱讀版，沒有排程、RSS訂閱、自動發布或API抓取。搜尋／篩選程式不會把訪客輸入傳送第三方模型。
